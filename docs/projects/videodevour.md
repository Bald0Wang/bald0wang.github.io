## 项目定位

"吃掉视频，输出一份图文并茂的报告。"——基于 **ASR + VLM** 技术的智能视频笔记工具：语音识别生成文本，LLM 提取章节结构，视觉模型挑选关键帧，最终产出带层级、有画面、有依据的结构化报告。

我对它的最终想象是一个**知识基建工具**：真正优质的 learning 材料往往在视频里（课程、技术分享、访谈、Talk），但"看完以后很难再次利用"。VideoDevour 要做的是把这些内容**提取出来、组织起来、沉淀下来，并且能够二次使用**——放进知识库、生成思维导图与知识图谱、在需要时重新调用。

## 核心能力

- **多信源接入**：B站、YouTube、抖音、微信视频号链接或分享文案 + 本地上传，统一进入"先预览、再下载、后沉淀"的链路
- **两种整理速度**：已有字幕的视频直接生成"字幕笔记"（不下载、不做 ASR）；需要完整沉淀时走全链路生成图文报告
- **一份报告多种读法**：图文大纲 / 精简报告 / 详细报告之外，可按需生成量子速读、公众号文章、小红书笔记、学习卡片、思维导图、知识图谱
- **本地知识库**：所有结果沉淀在本地，同一视频保留 V1/V2 版本，支持按标题、关键词或"记得的观点"检索，整库导出
- **桌面客户端**：pywebview 桌面壳 + 本地 FastAPI 服务，把"配置 Python、FFmpeg、模型依赖"的开发环境题变成普通用户可用的界面步骤

## 这个项目在做什么

2026 年 9 月，TypeSafe AI（创始人 Diogo Almeida，InstructGPT 与 RLHF 共同发明人之一）发布了业内首个「系统一模型」（System One Model）**Jev**。当 AI 从聊天窗口走进真实应用，它面对的大量环节不是"生成一段话"，而是"做一个可以被程序理解、检查和执行的判断"——Agent 该调用哪个工具、扫雷该揭开哪格、一句话指令对应哪台设备。

Jev Cookbook 是 Datawhale 社区发起的 Jev 中文开源教程：把抽象的"让 AI 做决定"拆成可以学习、运行和复盘的具体实验。每一章都回答同一个问题——**这个实验在验证什么，观察到了什么，又不能由此推出什么？**

## Jev 是什么（我的研究综述）

写作教程前，我完成了三篇深度研究报告（算法原理、性能基准、工程落地价值），核心结论：

- **设计哲学**：主流大模型（GPT、Claude）是依赖长思维链的"系统二"；而生产软件中的分类、路由、意图识别等高频控制流，本质是低延迟的"系统一"直觉判定。Jev 主动放弃自由文本生成，把模型接口限制为 **Choice / Score / Noul** 三类有类型、带概率的决策原语。
- **技术栈**：非自回归的硬件感知并行采样架构（状态前缀 KV 复用 + 多问题单次前向并行评估 + 直接读头输出概率分布），配合**校准决策强化学习 RLCD**——基于 Log Loss、Brier Score 等严格评分规则训练，让模型输出的概率具备统计学意义：大量样本下给出 80% 的判定，经验准确率收敛于 80%。
- **实测数据**：官方演示单次判断 0.114 秒（对照 GPT-5.6 Terra 为 8.566 秒）；官方四项工作流端到端最高 193.6× 提速、成本降至 1/444.6。⚠️ 这些均为厂商自测——公开点位匹配后的独立换算约为 25.3× 延迟、76× 成本优势；准确率约 67.8%，接近但尚未超过 frontier LLM（约 74%）。
- **定位判断**：Jev 不是 GPT 的替代品，而是"可编程判断器 / probabilistic if-statement / agent critic"。最优架构是组合式的：强 LLM 做规划与生成，Jev 做高频判断与路由，确定性代码做计算与执行，低置信度回落到强模型或人工。

## 教程结构（11 章 · 5 个阶段）

| 阶段 | 章节 | 内容 |
| --- | --- | --- |
| 提出判断题 | 1–3 章 | Jev 是什么；State 与 Noul、Choice、Score 三种问题原语；概率如何进入程序控制流 |
| 进入实际任务 | 4–5 章 | 18 个 Cookbook Notebook 配方（RAG、风险控制、结构化处理）；智能家居意图识别与动作派发 |
| 实验与项目检验 | 6–7 章 | 模型评测方法（正确率、概率校准、延迟、成本）；12 个游戏与应用项目（贪吃蛇、扫雷、狼人杀、Browser Use、Mario……） |
| 研究与 Agent | 8–9 章 | Jev-Mem 长期记忆的写入与检索路由；类型化判断接入 Agent 工具路由与安全门 |
| 模型与证据 | 10–11 章 | Laya 本地模型的数据构建、训练、校准路线；知识库证据核对与结论范围 |
